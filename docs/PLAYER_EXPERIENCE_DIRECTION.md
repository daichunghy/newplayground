# Player experience direction — October 2026

The default is immediate, intuitive play with very little visible text.

- Put the game board/action first. Remove marketing slogans, long tutorials, verbose stats, secondary panels and explanatory cards from the play surface.
- Show only essential counters, short labels or clear icons. Keep meaningful accessible names and nonvisual status feedback.
- Help is optional and compact, normally one or two short sentences. Research, licensing, detailed rules and QA stay in project documents or outside play.
- Remove setup chores and unnecessary configuration. Automate routine preparation when it does not erase the core game identity.
- Hàng Rong defaults to cooking and tapping customers; menus, purchasing stock, collecting dishes and matching service are handled automatically.
- Fresh sessions start immediately. Resume safety and a brief destructive-restart confirmation may remain.
- Animation should not swallow a player's next action. Respect reduced motion automatically.
- The same direction applies to all 150 catalog entries. Existing common legacy tutorial gates are skipped; supporting control prose is nonvisual while each game receives its deeper upgrade.

Initial-copy tests are static checks, not a browser layout or usability certification. Device/playtest gates remain separate. The prior richer prototype checkpoints remain in Git history; do not restore them as the default UI.
